# Example 3 — The evergreen page selling last spring's sale

## Before

The flagship features page still leads with "Spring sale — 30% off, ends April 30" in November, and its "new for this year" section describes a feature two versions old. The page was published with no owner and no review date, so expiring was nobody's job. Visitors reasonably read the banner as a live offer; support fields the complaints.

## After

The page carries a named owner and a review-by date set before the sale ends. At the review, the owner removes the expired banner, re-verifies the feature claims against the current release, and records what was checked. The sale itself lives on a campaign page whose brief includes its own end date and takedown step, so dated offers are never load-bearing on an evergreen page.

Note: corrects CO-085 — every published piece carries a named owner and a review-by date.
