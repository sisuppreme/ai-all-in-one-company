# Example 3 — Citation bait replaced with a sourced statistic

## Before

## Does a launch checklist reduce launch-day incidents?

Yes. Studies show that teams using a launch checklist have 73% fewer launch-day incidents, which is why every release plan should start with one.

## After

## Does a launch checklist reduce launch-day incidents?

A checklist reduces launch-day incidents when each item names an owner and a verification step, because the failures it prevents are omissions — a migration not run, a cache not warmed — rather than defects in the code itself. Our release template therefore pairs every checklist item with the command or check that proves it was done; items without a verification step are removed at review.

Note: corrects CO-051 (citations, quotations, and statistics added for citability must trace to a real source; the invented "73%" figure — a DET-CON-011 blocker — is deleted rather than softened).
