# Example 1 — Title and description rewritten from the finished page

## Before

A pricing page ships with the template's metadata, identical to nine other pages:

```html
<title>Our Products — Company</title>
<meta name="description" content="Add a description here">
```

## After

After the page is finished, its metadata is written from the actual content — a pricing page with three plans and a monthly/annual toggle:

```html
<title>Pricing — Three Plans, Monthly or Annual Billing</title>
<meta name="description" content="Compare the Starter, Team, and Scale plans side by side, with monthly and annual prices and what each plan includes.">
```

Note: corrects CO-022, CO-023, CO-024 — metadata written last from the finished page, unique per page, stating the topic and offer plainly.
