# Example 3 — Description promise and superlative removed

## Before

```html
<title>The #1 Project Tool for Teams</title>
<meta name="description" content="The best project tool — free forever, with unlimited storage for every team.">
```

The page itself offers a 14-day trial (not free forever), storage is capped per plan, and no ranking source supports "#1" or "best" anywhere on the site.

## After

```html
<title>Project Boards and Timelines for Small Teams</title>
<meta name="description" content="Plan projects on boards and timelines, assign owners, and track deadlines. Start with a 14-day trial of every plan.">
```

Every claim in the metadata now appears on the page and matches fact-sheet.md; the unsubstantiated superlatives are gone.

Note: corrects CO-027 and CO-029 — descriptions promise only what the page delivers, and unsourced superlatives are deleted, not softened (BAN-CO-013, BAN-CO-015).
