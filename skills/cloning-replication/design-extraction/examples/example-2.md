# Example 2 — Inline radius vs. compiled token

## Before

A card component in the rebuild ships with `border-radius: 10px` typed directly into its stylesheet because it "looked right." The extracted token for card radius is 8px, so this one template silently breaks the radius language while every other page matches.

## After

The card stylesheet references the compiled variable `var(--radius-card)`, generated by Style Dictionary from the token file's `radius.card = 8px`. The orphan-value scan (G-CL-022) greps the built CSS and finds zero literals that exist in no token.

Note: corrects CL-049 / BAN-CL-022 — rebuild values are compiled from the token file, never hand-typed per page.
