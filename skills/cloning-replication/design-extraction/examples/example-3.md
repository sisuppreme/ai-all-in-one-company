# Example 3 — Logo as asset vs. replace-list entry

## Before

During extraction, the source site's logo SVG and its headline copy are saved into the rebuild's asset folder "so the header matches." The clone ships carrying the target's trademark and text.

## After

The extraction records only measurements: logo slot 148×32px at the header's inline-start, headline set in the extracted type scale. The logo file and the headline string go on the replace-list — "operator supplies own mark and copy" — and never enter the token file or asset folders. The G-CL-024 review confirms the token file contains measurements only.

Note: corrects CL-051 / BAN-CL-024 — the target's branding and copy are replace-list items under clone-ethics, never reusable assets.
