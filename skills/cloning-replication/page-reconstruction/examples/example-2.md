# Example 2 — The gated admin console

## Before

The client's admin console sits behind a login and has no archived captures. The builder assembles a plausible dashboard from common admin patterns — sidebar, stat cards, a users table — and delivers it as a "verified clone of the admin console," so the client believes the real console was reproduced.

## After

The row is labeled `designed`: no capture exists and the client has not yet provided access. The console is built fresh in the extracted design system from the client's functional requirements, delivered as "new design in the source's system," and the delivery note states plainly that parity cannot be claimed until the client provides access or evidence for comparison.

## Note

Demonstrates CL-104 and CL-109: parity claims attach to `captured` pages only, and a gated page is reconstructed from client-provided access or evidence — never invented and never reached by bypass.
