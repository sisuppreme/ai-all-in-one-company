# Example 3 — Recovered copy in the rebuild

## Before

A capture of the target's landing page survives in full. The rebuild lifts the page wholesale: the target's headlines, body copy, hero photograph, and logo are pasted into the new site so it "matches the original exactly," including a testimonial from one of the target's customers.

## After

The capture is used as a structural reference only: section order, hierarchy, and approximate text lengths are noted in the inventory row. The page is then built in original code from the design-token file, filled with the operator's own headlines, copy, photography, and logo, and each replaced asset is listed in the build notes. The testimonial is dropped entirely — it is the target's content, not the operator's.

## Note

Demonstrates CL-106 and CL-107: reconstruction reproduces structure and function, while copy, data, and branding always come from the operator; the target's assets never ship.
