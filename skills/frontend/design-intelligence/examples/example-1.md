# Example 1 — Ledgerline: template default replaced by a decided build

Corrects rules **FE-321** (decide before designing) and **FE-322** (audience trust outranks brand ego); the full reasoning record is §7, Example A of the skill.

## Before

A B2B accounting SaaS ships the framework starter with a fintech palette swapped in: dark cinematic hero, kinetic-type headline, animated counters quoting unsourced market-size numbers, dial-4 spectacle throughout. Nothing was decided — the template was decorated. For an audience of CFOs and finance leads who have been burned by flashy fintech before, the spectacle reads as risk: the louder the page, the less they trust the books behind it. Symptoms 1, 9, and 12 from the §4 anti-slop table, live on one page.

## After

The decision record runs first (§1): archive/instrument theme family, bento + editorial hybrid layout, dial 2, restrained neutrals with one accent, grotesque body with mono for data. The signature element is a ledger line in the pricing section that draws itself across the table and *balances* — debit and credit columns animate to the plan's real totals, so the element is the product's core promise carrying real figures, and it passes all four merge tests (§3.3). Rejected, with reasons recorded: the dial-4 cinematic theme (spectacle reads as risk to this audience — FE-322), the kinetic-type hero (the claim must stay quotable), and the market-size counters (unsourced — §4, symptom 9). The page is scored under §5 before it ships (G-FE-162).
