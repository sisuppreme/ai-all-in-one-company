# Example 3 — Exam-prep content site: cinematic default replaced by a scannable build

Corrects rules **FE-323** (the dial is set once, by content type) and **FE-326** (every technique has a job); the full reasoning record is §7, Example C of the skill.

## Before

An exam-prep content site for students is built like a launch microsite: pinned cinematic chapters the reader must scrub through, a custom cursor trailing the pointer, spectacle at dial 4, counters animating round invented numbers. The audience — students on mid-range Android phones, returning daily under time pressure in the weeks before exams — is punished by every one of those choices: scrubbing fights scanning, the cursor fights the pointer (BAN-FE-164), and the invented numbers teach students to distrust the real ones.

## After

The decision record sets dial 2 from the content type (editorial/reference) before anything is built: dense scannable grid, light airy posture with one accent, grotesque body with mono reserved for counts and dates. The signature element is a progress spine running down each guide that fills as topics are checked off and holds the student's place between visits — the element *is* the study plan, not decoration beside it. Counters appear only where real counts exist (papers actually counted, documents actually in the library). Reveals fire once per session, nothing is pinned, and every animation is checked against the §5 performance category on a cheap phone. Rejected, with reasons recorded: pinned chapters (§3.1 — scrubbing fights scanning), the custom cursor (banned outright for this audience), and dial 4 (brand ego over audience — FE-322).
