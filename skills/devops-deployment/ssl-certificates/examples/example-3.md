# Example 3 — Tutorial TLS defaults and an http:// script

## Before

The server block was copied from an old tutorial and shipped unexamined:

```nginx
ssl_protocols TLSv1 TLSv1.1 TLSv1.2;
ssl_ciphers "ALL:!aNULL:!MD5";
```

A scan shows TLS 1.0, TLS 1.1, and obsolete ciphers enabled, with no documented reason. The HTTPS homepage also loads its bundle over plain HTTP:

```html
<script src="http://cdn.example.com/app.js"></script>
```

The browser console reports mixed content and blocks the script.

## After

The TLS settings follow the Mozilla Intermediate profile (TLS 1.2/1.3, profile cipher list) as generated by the Mozilla SSL Configuration Generator for the server in use:

```nginx
ssl_protocols TLSv1.2 TLSv1.3;
ssl_prefer_server_ciphers off;
```

Every resource reference uses HTTPS:

```html
<script src="https://cdn.example.com/app.js"></script>
```

A post-change `testssl.sh example.com` run records the grade and protocol list in progress.md; the console shows zero mixed-content warnings.

Note: corrects DO-224, DO-229 — Mozilla Intermediate profile applied; zero `http://` references on HTTPS pages.
