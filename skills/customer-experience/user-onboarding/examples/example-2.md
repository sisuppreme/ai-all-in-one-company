# Example 2 — Replacing a placeholder workspace with a real first action

## Before

Every new workspace is seeded with three dummy projects — "Sample Project —
delete me", "Demo Board", and "Test Campaign" — plus two fake teammates, so
the dashboard "doesn't look empty."

New users spend their first session deleting records they never made, unsure
which ones are safe to remove. Some keep the dummy data for months and build
real work on top of it; others delete a seed record the product quietly
depended on and break their own workspace.

## After

The workspace starts genuinely empty, and the empty state does the teaching:

1. All seed projects and fake teammates are removed from account creation.
2. The empty dashboard names the core action — "Create your first project" —
   with the button that starts it, completable with the user's real data.
3. An optional "Start with a sample project" link remains for explorers; the
   sample is labeled as sample everywhere it appears and one "Remove sample
   data" action deletes all of it at once.

The first thing a new user touches is their own work, not the team's
placeholder.

Note: corrects CX-066 — steps are completed with the user's real data; sample content is labeled, optional, and removable in one action.
