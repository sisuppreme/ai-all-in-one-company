# Example 3 — Tiers copied from a competitor

## Before

A team launches pricing by copying the market leader's shape: three tiers at $12 / $29 / $79 per user, with features fenced to look similar ("the middle one is the popular one"). Six months later the pattern is clear: their own customers are solo consultants who never add a second seat, so the per-seat metric charges for something customers do not value, nobody upgrades (the fences guard features nobody wants), and the $79 tier has four customers total.

## After

The pricing is rebuilt from the value metric. Research shows customers get value per *client project delivered*, so the value metric is active projects:

| Tier | Price | Derivation |
|---|---|---|
| Starter | $15/month | Up to 3 active projects — covers a solo consultant's typical load |
| Studio | $39/month | Up to 15 active projects — the level growing practices actually reach |
| Agency | $89/month | Unlimited projects + client portal — for firms whose project count is the business |

Arithmetic check against the metric: a consultant running 3 projects at $15 pays $5.00 per project; a practice at 15 projects on Studio pays $2.60 per project — unit price falls as value grows, so graduating is attractive instead of punitive. Features are identical across tiers except project count and the portal, because the fences now sit on the value metric itself, not on withheld conveniences.
