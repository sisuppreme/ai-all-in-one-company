# Example 3 — Overclaiming statement vs. truthful statement with exceptions and feedback route

## Before

Published accessibility statement:

> "This website fully conforms to WCAG 2.2 Level AA. If you encounter an accessibility problem, please contact us."

The latest audit report rates checkout step 3 "does not support" for criterion 1.4.3 and lists the third-party payment widget as an open finding. The statement names no exceptions, carries no date, and "contact us" is not linked to any route.

## After

Published accessibility statement (excerpt):

> "Accessibility statement — prepared 2026-11-21, based on audit report A11Y-2026-11.
> Conformance status: partially conformant with WCAG 2.2 Level AA. Known exceptions: (1) checkout step 3 — placeholder text fails criterion 1.4.3, fix scheduled; (2) the embedded payment widget (vendor named in the audit report) does not fully support keyboard operation, criterion 2.1.1; an assisted checkout route is available on request.
> Feedback: report a barrier via the [accessibility feedback form](/accessibility/feedback) (route owner: support lead; test-submitted and confirmed received 2026-11-21)."

Note: the statement claims exactly what the audit supports, lists every known exception, and publishes a tested feedback route, per AC-068.
