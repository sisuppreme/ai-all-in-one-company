# SKILLS_INDEX.md — the skill catalog

Generated by `scripts/build-index.py` from the skills' own metadata — **do not hand-edit**; edit the skill and re-run the script.

**Repo-first use:** read `BOOTSTRAP.md` first. Then scan this index by department section and Keywords to identify the skills a task needs — do not read every entry, and do not load a skill until the index says it fits. Match task type to a playbook first; else match task keywords to the Keywords field; if nothing matches, load the core bundle and ask the user (§5.2).

**Excluded:** `skills/detection/` — detection parameters are indexed inside their own `PARAMETERS.md` files, not in this catalog.

**Fields** (per §5.3): *Depends on* = must load first (prerequisite); *Feeds into* = skills that consume this one's output; *Load with (derived from metadata)* = the skill's declared Depends-on ∪ Feeds-into neighbours, commonly used together (optional); *Size* = SKILL.md line count / token estimate, where tokens = ceil(characters ÷ 4) over the raw file — budget before loading; *Keywords* are derived from the skill name and its own Use-when line; *Anatomy element* = the `docs/PROJECT_ANATOMY.md` element(s) the skill serves.
