# User Brief — Project Kickoff Intake

Fill in this form when handing a new project to an agent that works from this repository. One completed brief per project. Answer in your own words; leave a section blank rather than guessing — a blank tells the agent to ask, a guess tells it to build the wrong thing.

The agent uses this brief to pick a playbook, write the project's `fact-sheet.md`, and plan the build. Nothing in this brief is content for the project itself: every fact that ends up on a page or in a document must still be verified against a source.
