# Contract: D14 → D16 — Clone Ethics

- **Backbone link:** #12 of 13 (MASTER_BRIEF.md §3.11)
- **Link type:** CONSTRAINS
- **Owner department:** D14 Legal & Privacy
- **Consumer department:** D16 Cloning & Replication
- **Liaisons:** D14 Compliance auditors ↔ D16 Site crawlers & discovery
- **Skills on each side:** clone-ethics, licensing (D14) → site-discovery, asset-harvesting, behavior-cloning, page-reconstruction (D16)

## Artifact that passes

The clone authorization record: a pre-committed, dated artifact in the project
repo naming the target, the legal basis for cloning it (ownership, license, or
other authorization), the scope (which pages and assets), and the approver.
It exists before any crawl, harvest, or reconstruction begins — it is a
structural precondition, not a self-approval form.

## Format

Markdown record per the clone-ethics skill (LG-181): dated, committed to the
project repo before the first target request, with license evidence attached
for any asset marked `licensed`. The manifest tooling itself rejects a
`licensed` row whose approver is the harvesting actor.

## When it passes

Once, before the first crawl request of a project — and again whenever the
target, scope, or legal basis changes. No target request of any kind precedes
the record; robots.txt and sitemap fetches are the first *authorized* step,
not an exception to this one.

## Acceptance test (how the receiver verifies)

**Joint gate — ethics.** D16's pre-flight gates (clone-ethics G-LG-091/092/093)
run automatically: the authorization record exists and is complete; its
timestamp precedes the first crawl timestamp; every harvested asset carries a
manifest row with a lawful basis. D14 audits the record itself — target,
basis, and scope match what was actually crawled.

## If the test fails

Everything stops, fail-closed. Crawled material gathered without a valid
record is quarantined and deleted, not used; the project restarts only under
a corrected record. Under §5.7 precedence, legal/privacy (rank 2) beats clone
fidelity (rank 16) on every conflict.
